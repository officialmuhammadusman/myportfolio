## What is included
- Services, Work, About, Insights, CTA, UI and Social icon sets.
- Base duotone, hover, single-color orange, white and black SVG variants.
- Transparent PNG fallbacks at 48px, 96px (@2x), and 144px (@3x).
- Circle and plain social versions.
- Work, About, Insights and project placeholder panel images.
- Animated-layer MU mark and motion CSS.
- One-page usage sheet in PNG and PDF.

## Implementation notes
- SVGs use a 64x64 viewBox. Use CSS width/height to render at 20, 24, 32 or 48px.
- Primary icons use orange + amber. Use `--white` on dark surfaces where stronger contrast is required and `--black` on light surfaces.
- The About panel uses an abstract editorial founder silhouette, not a likeness. Replace it with a real portrait later while retaining the same crop and grade.
- The animated MU mark exposes `#mu-m`, `#mu-u`, and `#mu-tip` layers.
- No external stock imagery, purple, neon glow, cartoon or 3D-plastic styling is used.
